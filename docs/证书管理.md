# 证书管理模块文档

> 最后更新：2026-07-15

## 概述

证书管理模块为游雁学院提供电子证书的全生命周期管理：模板管理 → 证书定义 → 颁发 → 学员查看/下载。

## 体系结构

```
12 套内置 PNG 模板（v1-v6 竖版 + h1-h6 横版）
   ↓
[前端] 可视化编辑器（拖拽 / 文字编辑 / 印章 / 背景）
   ↓
[Server] design 数据落库到 certificates[].design
   ↓
[颁发流程] issueCertificateInternal → generateCertificateImage → PNG 落盘
   ↓
[学员端] 个人中心 / 消息中心直接读取 PNG (imageUrl)
```

## 后端 API

### GET /api/certificates/templates
返回 12 套模板的元数据，用于"模板选择"弹窗。
- **响应**：`{ success: true, data: [{ id, name, layout, thumbnail, style, placeholders }] }`
- **数据源**：`server.js` 中的 `BUILTIN_CERT_TEMPLATES`（运行时动态生成，不依赖 data.json）

### POST /api/certificates
创建证书定义。`templateId` 必须是 12 套模板之一。
- **请求**：`{ name, templateId, validityType, validityDays, prefix, startNumber, digits, design, ... }`
- **校验**：`templateId` 必须匹配 `^[vh]\d$` 正则
- **响应**：`{ success: true, data: certificate }`

### POST /api/certificates/preview
**所见即所得**的关键端点。管理后台编辑器内调用，server 用 Playwright 实时渲染 PNG 并以 base64 dataURL 返回。
- **请求**：`{ design, fill? }`，fill 默认值见下方
- **fill 默认值**：
  ```js
  {
    title: '荣誉证书',
    subtitle: 'CERTIFICATE OF HONORS',
    name: '张三',
    certNo: 'CERT0001',
    date: '2026-07-15',
    company: '广州游雁网络科技有限公司',
    content: '...'
  }
  ```
- **响应**：`{ success: true, data: { dataUrl, width, height } }`
- **性能**：单次渲染约 1-2s（含 Playwright 启动开销），前端调用建议加 debounce（当前 600ms）
- **依赖**：`playwright` 包 + 已下载的 Chromium

### GET /api/certificates
证书定义列表。`template` 字段通过 `getBuiltinTemplate(templateId)` 动态从 12 套模板元数据中查出。

### POST /api/certificates/:id/issue
颁发证书。流程：
1. `issueCertificateInternal` 写入 user_certificates 记录
2. `generateCertificateImage` 渲染 PNG 到 `uploads/certificates/${userCertId}.png`
3. `userCert.imageUrl` 指向该 PNG
4. 写通知消息

### GET /api/user-certificates
查询用户证书。`imageUrl` 字段直接返回颁发时生成的 PNG URL 路径。

## 关键设计决策

### 为什么删除旧 4 套 CSS 渐变模板？
旧 4 套（紫色/金色/绿色）通过 CSS 渐变模拟背景，**不真实**——文字叠加、印章位置、版式都偏离预期。改用 12 套真实 PNG 模板后，每个模板的版式（标题位置、副标题位置、姓名位置等）都是真实印刷品的留白，文字叠加位置准确。

### 为什么需要所见即所得？
旧版流程：管理后台编辑器展示的是**简化版 HTML 预览**（用 `renderDesignPageInner` 在前端画），但颁发给学员时用 Playwright 重新渲染成 PNG。两套渲染管线存在细微差异，导致管理后台看到的和学员看到的**不完全一致**。

新版流程：管理后台和颁发流程**共用同一套渲染管线**（`certRenderDesignPageInner` + `renderDesignToPngBuffer`），管理后台实时调用 `/api/certificates/preview` 拿到的就是和颁发时一模一样的 PNG，从根本上解决所见非所得的问题。

## 文件清单

### 前端
- `js/certificate-management.js` — 证书管理主模块（含 CERT_TEMPLATES 12 套定义、可视化编辑器、模板选择器、用户证书打印）
- `dashboard.html` — 管理后台布局 + 证书管理抽屉
- `center.html` — 个人中心"我的证书"列表（通过 `userCert.imageUrl` 展示 PNG）
- `messages.html` — 消息中心"证书通知"（通过 `dataUrl` 展示 PNG 缩略图）

### 后端
- `server.js` — 证书 REST API、`BUILTIN_CERT_TEMPLATES`、`certRenderDesignPageInner`、`renderDesignToPngBuffer`、`generateCertificateImage`、`issueCertificateInternal`

### 资源
- `uploads/cert-templates/cert-v1.png` ~ `cert-h6.png` — 12 套真实证书模板（**唯一素材源**）
- `uploads/certificates/${userCertId}.png` — 颁发后生成的证书 PNG（学员端直接读取）

### 数据
- `data.json`:
  - `certificates` — 证书定义（含 `design` 字段）
  - `user_certificates` — 学员证书实例（含 `imageUrl` 字段）
  - ~~`certificate_templates`~~ — **已废弃**（旧 4 套模板已清空）

## 维护注意事项

1. **修改模板元数据时**：必须同步前端 `CERT_TEMPLATES` 和后端 `BUILTIN_CERT_TEMPLATES`，否则渲染结果会不一致。

2. **新增/替换模板时**：上传 PNG 到 `uploads/cert-templates/cert-{key}.png`（v1-v6 竖版尺寸建议 1425x2064，h1-h6 横版建议 2598x1795），同时更新两个常量。

3. **清理过期 userCert.imageUrl**：删除证书定义时（DELETE /api/certificates/:id）会同步清理 user_certificates 中的关联记录，但 **uploads/certificates/ 下的 PNG 文件需要手动清理**。

4. **Playwright 启动失败时**：`/api/certificates/preview` 和颁发流程的 PNG 生成会失败。检查 `node_modules/playwright/.local-browsers/` 目录是否完整。
